PDF to CSV FAQ

Does PDF to CSV work on scanned tables?

No. A scan is a picture: there are no text runs to group into rows, so nothing is detected. Run OCR PDF first and the recognised text can then be turned into a table. When nothing is found the tool says "no table found" rather than exporting an empty or one-column file.

What happens to merged cells and cells with two lines of text?

CSV cannot express a cell that spans two columns, so the value is written once and the next column stays empty. Text that wraps onto two lines becomes two rows. Check the first few rows before you rely on the file.

The columns are misaligned — why?

Detection reads the space between runs, so columns that sit very close together, or right-aligned numbers of very different widths, can land in the wrong cell. Comparing the first rows against the page is the quickest way to spot it; a table with a clear gutter between columns converts cleanly.

What do I get back after using PDF to CSV?

You get CSV files — one per page that has a table, zipped when there are several.

Do I need an account to use it?

No account, no email and no credit card. Open the page, add your file and download the result.

Is this safe for confidential documents?

Yes. The work happens locally, so no copy of your document is stored anywhere. There is no upload step to leak and no server-side queue to wait in.

Does it work on a phone, and can I use it offline?

Yes. The page works in any modern browser on desktop, tablet or phone, and once it has loaded it keeps working with no connection.
