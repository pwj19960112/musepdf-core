    Local by default, on your device

    Every one of the 60 tools runs with JavaScript and WebAssembly in your own browser tab. In local mode there is no upload step and no server-side copy. Cloud features — only the ones you choose — are the single labelled exception.

    Fast, even for large files

    No upload queue means a 200-page document is processed at the speed of your own machine — and it keeps working offline once the page has loaded.

    Free with no catch

    No account, no trial, no watermark and no daily cap for the 60 local tools. The project is open source under Apache-2.0, so you can read every line of what runs.

    Two modes, one site

    Local mode — the default

    All 60 tools run in your browser with JavaScript and WebAssembly. Your file is opened on your device and not sent anywhere: free, no account and no daily cap. Nothing to install.

    Cloud mode — optional, metered

    Some features will need more power than a browser tab can give — talking to a PDF, translation, table extraction, OCR, PDF to PowerPoint, and very large files. When you choose one of those, the file (or the part of its text that step needs) is uploaded for that step only. They are labelled and metered, and they only ever run when you pick them.

    Frequently asked questions

    Is MusePDF free?

    The 60 local tools are free with no signup, no watermark and no daily limit. Optional cloud features cost server time, so they are metered and some will be paid.

    Do my files get uploaded?

    For the 60 local tools, no — they run in your browser and your file stays on your device. Optional cloud features (AI, very large files) upload the file, or the text they need, for that step only.

    Do I need to install anything?

    No. MusePDF runs in any modern browser on desktop, tablet or phone, and works offline once loaded.

    How many tools does MusePDF include?

    MusePDF includes 60 PDF tools covering merging, splitting, converting, editing, organising, optimising and securing documents.

    What happens to my file when I use a cloud feature?

    It is used only to produce your result for that one step, and cloud steps are always opt-in.
