修改文字颜色常见问题

修改文字颜色 之后我会得到什么？

你会得到文字重新着色后的同一个 PDF。

要花钱吗？

不用花钱。完整功能免费用，不用注册、不留邮箱、不加不印水印，处理多少个文件也没有限制。

文件在哪里处理？

就在你自己的浏览器标签页里。不会上传到服务器，文件始终留在你的电脑上 —— 关掉标签页，数据也就没了。

手机上能用吗？能离线用吗？

可以。这个页面在电脑、平板和手机的现代浏览器里都能用，加载完之后断网也能继续用。

如何在不把文件上传到服务器的情况下完成PDF 文字改色？

修改文字颜色 在你的浏览器里用 JavaScript 和 WebAssembly 读取文件，处理全部在你自己的设备上完成：不会上传到任何服务器，关掉标签页数据也就消失了。

PDF 文字改色免费吗？有没有次数或文件大小限制？

完全免费：不用注册、不留邮箱、没有水印，也没有每日次数上限。能处理多大的文件取决于你设备的内存，而不是某个上传配额。

PDF 文字改色的改动真的写进 PDF 了吗？

写进去了。改变 PDF 文字颜色，把褪色扫描件和对比度过低的文档重新变清楚。保存后的文件在任何阅读器里看到的都是同一版内容。
