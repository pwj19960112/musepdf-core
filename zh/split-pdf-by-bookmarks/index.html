    能做什么

    每个一级书签一个文件，文件名取自章节标题

    第一个书签之前的封面、目录会并入第一份

    最后一个书签之后的内容留在最后一份

    扫描件与文字版 PDF 都能用——拆分依据是书签这种元数据

    ：3 步完成

    1. 加入 PDF

      先读取目录结构；如果文件没有书签，工具会直接说明，而不是乱猜。

    2. 核对章节列表

      每个书签都会显示它将变成哪几页。

    3. 下载 ZIP

      每个章节一个 PDF，文件名取自书签标题，全部在你的本地生成。

    文档需要重新组装而不是重写的时候，就用 —— 把几份 PDF 拼成一份报告、从 200 页的手册里抽出某一章、删掉扫描仪多扫出来的空白背面。由于每一页都在你自己的电脑上处理，能处理的文件大小和页数取决于你的浏览器，而不是上传配额。

    不上传

    文件在本地用 JavaScript 和 WebAssembly 读取 —— 这个工具不会把内容发送到服务器。

    免注册

    不用账号，不用邮箱，不用信用卡，也没有到期要记的试用期。

    无水印

    下载到的就是真正的文件 —— 干净、没有标记、可以直接打印。

    常见问题

    我的 PDF 没有书签怎么办？

    那就没有拆分点：可以先用「编辑书签」工具手动加上章节书签，或改用「按大小拆分 PDF」。

    能按二级小节拆吗？

    本工具只按一级书签拆——书籍和合同通常就是这个层级。嵌套的小节会留在它所属的章节里。

    文件会上传吗？

    不会。PDF 在这个标签页里用 JavaScript 读取，拆分也在本地写出，不会发送到任何服务器。

    之后我会得到什么？

    你会得到。

    用的时候需要注册账号吗？

    不用账号、不用邮箱、不用信用卡。打开页面、添加文件、下载结果就行。

    机密文件用它安全吗？

    安全。处理都在本地完成，文档不会在任何地方留下副本。没有会泄露的上传环节，也没有要排队的服务器队列。

    手机上能用吗？能离线用吗？

    可以。这个页面在电脑、平板和手机的现代浏览器里都能用，加载完之后断网也能继续用。

    扫描件没有书签，能按章节拆吗？

    不能——拆分点来自 PDF 的书签（目录）结构。扫描件先 OCR 并加上书签（可以用「编辑书签」工具手动添加章节），再回来按书签拆分。

    拆出来的文件名会是章节标题吗？

    会。每个文件取对应书签的标题，前面加序号（例如 01-第一章.pdf），并自动去掉斜杠、冒号等不能出现在文件名里的字符。

    第一个书签不是第 1 页，中间的页会丢吗？

    不会。第一个书签之前的页面（封面、目录）会并入第一份；最后一个书签之后的页面并入最后一份，总页数与原件一致。
