合并成单页常见问题

合并成单页 之后我会得到什么？

你会得到一张连续的长页面。

这个工具真的免费吗？

真的。这里每个工具都免费，不用注册、没有试用期、不加不印水印。没有每日次数限制，也没有需要付费才能导出的功能 —— 整套工具都是开源的。

我的文件会上传到服务器吗？

不会。合并成单页 完全在你的浏览器里用 JavaScript 和 WebAssembly 运行，文件在你的设备上处理，这个工具不会上传。合同、发票、证件以及任何受保密协议约束的文件都适用。

手机上能用吗？能离线用吗？

可以。这个页面在电脑、平板和手机的现代浏览器里都能用，加载完之后断网也能继续用。

如何在不把文件上传到服务器的情况下完成PDF 合并成单页？

合并成单页 在你的浏览器里用 JavaScript 和 WebAssembly 读取文件，处理全部在你自己的设备上完成：不会上传到任何服务器，关掉标签页数据也就消失了。

PDF 合并成单页免费吗？有没有次数或文件大小限制？

完全免费：不用注册、不留邮箱、没有水印，也没有每日次数上限。能处理多大的文件取决于你设备的内存，而不是某个上传配额。

PDF 合并成单页时可以自己决定页面顺序吗？

可以。把每一页竖向叠起来，合成一张连续的长页面。顺序由你排，导出之前随时能再调整。
