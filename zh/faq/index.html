常见问题

有疑问？这里有答案。下面是大家最常问 MusePDF 的几个问题。

我的文件安全、私密吗？

当然。 这是 MusePDF 最重要的特性。60 个本地工具 100% 在你的浏览器里运行，文件在你的设备上处理，不会被上传。少数可选的云端功能（AI、超大文件）会为该步骤把文件或它需要的文本发送到我们的服务器；这些功能都会明确标注、只在你主动选择时运行，你不选就不会有任何上传。

MusePDF 真的免费吗？有什么猫腻？

这 60 个本地工具完全免费：没有隐藏费用、没有订阅、也没有使用次数限制。可选的云端功能会消耗服务器资源，因此按用量计费 —— 上线后部分会收费。

用这些工具需要联网吗？

第一次打开网站之后，大多数工具都能完全离线使用。因为所有处理库都加载进了浏览器，你断网之后照样可以安全地合并、拆分、压缩和编辑 PDF。少数需要外部数据的工具（比如带网络图片的 Markdown 转 PDF）可能仍需联网。

有文件大小或使用次数限制吗？

本地工具不设人为的文件大小或使用次数上限 —— 唯一的实际限制是你自己电脑的内存，所以超大文件会更慢。如果文件大到浏览器处理不了，工具会在开始前提示你。

为什么我的 PDF 处理失败了？

失败很少见，但可能有这几种原因：

  • PDF 可能已损坏，或者不符合标准规范。
  • 文件可能用了你没有的密码加密。请先用我们的解密工具处理。
  • 文件可能是特殊的「XFA」或动态表单型 PDF，部分工具无法处理。

你们会追踪我在 MusePDF 上的操作吗？

我们重视你的隐私。MusePDF 通过 Google Tag Manager 使用 Google Analytics 统计匿名访问量、了解哪些工具被使用 —— 不涉及个人信息。分析代码只在页面加载完成后才载入，并以无 Cookie 模式运行（不写 Cookie、不含标识符），也不会收到文件名、文件内容或搜索文本。

MusePDF 用了什么技术？

MusePDF 建立在现代 Web 技术之上。我们主要使用 PDF-lib.js 和 PDFKit.js 这类 JavaScript 库通过 WebAssembly 编译后在浏览器里高效运行，让浏览器内也能有接近服务器的处理能力 —— 对这些工具来说，数据留在你自己的电脑上。

使用云端功能时，我的文件会怎样？

它只用于完成那一步的结果，而且云端步骤始终由你主动触发。云端功能会为该步骤上传文件或它需要的文本 —— 只有你主动选择时才会运行。
