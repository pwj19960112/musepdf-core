全部工具

MusePDF（灵犀）：60 个 PDF 工具，直接在浏览器里运行，默认本地处理

直接在浏览器里合并、拆分、压缩、签名、转换和编辑 PDF。默认就是本地模式：不上传、不需注册、不加水印。

    没有匹配的工具。

    把文件拖到这里，或点击选择 支持 PDF、Word、Excel、PowerPoint 和图片等 —— 选好文件后再挑工具

    默认本地处理 免注册 无水印 加载后可离线使用

    默认本地，在你的设备上

    全部 60 个工具都在你自己的浏览器标签页里用 JavaScript 和 WebAssembly 运行。本地模式下没有上传环节，也不会产生服务器副本。唯一的例外是云端功能 —— 而且只有你主动选择时才会用到，各自的页面会写清楚。

    大文件也够快

    没有上传队列，200 页的文档就以你自己电脑的速度处理 —— 页面加载后还能离线使用。

    免费，没有套路

    这 60 个本地工具不用注册、没有试用期、不加水印，也没有每日次数上限。项目基于 Apache-2.0 开源，运行的每一行代码你都能查阅。

    两种模式，一个站点

    本地模式 —— 默认

    全部 60 个工具都在你的浏览器里用 JavaScript 和 WebAssembly 运行。文件在你本机打开，不发送到任何地方：免费、无需账号、不限次数，也不用安装任何东西。

    云端模式 —— 可选、按量计费

    有些功能需要浏览器标签页给不了的算力 —— 与 PDF 对话、翻译、表格提取、OCR、PDF 转 PPT，以及超大文件。当你选择其中一项时，文件（或那一步需要的那部分文本）会为该步骤上传。它们都会明确标注、按用量计费，而且只在你主动选择时才会运行。

    全部 60 个 PDF 工具

    选工具、拖入文件、下载结果。下面每个工具都有自己的页面，全在你本地浏览器里运行。

    合并与拆分

    合并、切割和重排文档，全程不上传。

    合并 PDF 把多个 PDF 合成一个文件。 拆分 PDF 把指定范围的页面导出成新 PDF。 页面等分 把页面横向或纵向一分为二。 按大小拆分 PDF 把 PDF 拆成每份都不超过指定大小的几个文件。 提取页面 把选中的页面另存为新文件。 删除页面 从文档里移除指定页面。 合并成单页 把所有页面接成一条长页。 交替合并 把多个 PDF 的页面交替拼在一起。 页面倒序 把文档所有页面的顺序反过来。 按书签拆分 每个一级书签一个文件，文件名取自章节标题。

    转换为 PDF

    在浏览器里把图片、文本和办公文件变成干净的 PDF。

    JPG 转 PDF 把一张或多张 JPG 图片做成 PDF。 PNG 转 PDF 把一张或多张 PNG 图片做成 PDF。 WebP 转 PDF 把一张或多张 WebP 图片做成 PDF。 SVG 转 PDF 把一张或多张 SVG 图片做成 PDF。 BMP 转 PDF 把一张或多张 BMP 图片做成 PDF。 HEIC 转 PDF 把一张或多张 HEIC 图片做成 PDF。 TIFF 转 PDF 把一张或多张 TIFF 图片做成 PDF。 文本转 PDF 把纯文本文件变成 PDF。 图片转 PDF 把各种图片合成一个 PDF。 Word 转 PDF 把 Word 转成 PDF：.docx 的段落、列表、表格和图片会排版到真正的 PDF 页面上，下载前可以先预览。 Markdown 转 PDF 把 Markdown 转成 PDF，标题、列表、代码块和表格都排好，适合文档和 README。 扫描成 PDF 用摄像头把纸张拍成 PDF：逐页拍摄、校正透视，然后导出 PDF。

    从 PDF 转换

    把 PDF 页面导出为图片、文本或压缩包。

    PDF 转 JPG 把 PDF 的每一页转成 JPG 图片。 PDF 转 PNG 把 PDF 的每一页转成 PNG 图片。 PDF 转 WebP 把 PDF 的每一页转成 WebP 图片。 PDF 转 BMP 把 PDF 的每一页转成 BMP 图片。 PDF 转 TIFF 把 PDF 的每一页转成 TIFF 图片。 PDF 打包成 ZIP 把多个 PDF 文件打包成一个 ZIP。 PDF 转 Markdown 把 PDF 转成 Markdown，把标题、列表和文字提取成文档工具和大模型都能读的格式。 PDF 转文本 把 PDF 的文字提取成纯文本 .txt 文件。 PDF 转 CSV 把 PDF 里的表格导成 CSV，每页一个文件。 PDF 转 Excel 把 PDF 表格写成真正的 .xlsx，每页一个工作表。 提取 PDF 图片 把 PDF 里内嵌的图片全部导出，打包成 ZIP。 PDF 转灰度 把所有颜色转成黑白。 PDF 转 Word 把 PDF 的文字提取成可编辑的 .docx 文档。

    编辑与批注

    发送前给 PDF 批注、签名、盖章、换样式。

    添加水印 在 PDF 页面上盖上文字或图片。 添加页码 给文档插入页码。 页眉页脚 在页面顶部和底部加文字。 修改文字颜色 改变 PDF 里文字的颜色。 修改背景颜色 改变 PDF 的背景颜色。 颜色反色 给 PDF 做一版“深色模式”。 裁剪 PDF 裁掉 PDF 每一页的边距。 旋转 PDF 以 90 度为单位转动页面。 移除批注 清掉评论、高亮和链接。 添加空白页 在 PDF 里任意位置插入空白页。

    整理页面

    重排、复制和排版页面，让文档按你要的样子打印。

    整理 PDF 拖拽调整页面顺序。 复制与整理 复制、重排和删除页面。 N-Up 拼版 把多页排在同一个版面上。 分块打印 把一个大页面拆成多个小页面。 PDF 叠加 把一个 PDF 叠到另一个上：信头纸、水印或预印表单。 添加附件 把文件嵌进 PDF，让它们跟着文档一起走。 PDF 小册子拼版 把页面按两页一版重排，双面打印机就能打出可对折的小册子。

    优化

    压缩、调整尺寸、清理 PDF，让它加载快、打印准。

    压缩 PDF 缩小 PDF 的文件体积。 统一页面尺寸 把所有页面统一成一种尺寸。 移除空白页 自动识别并删除空白页。

    安全

    文件离开你的电脑之前，加密、解密、清除痕迹。

    加密 PDF 给 PDF 加上密码保护。 解密 PDF 去掉 PDF 的密码保护。 移除元数据 清除 PDF 里的隐藏数据。 编辑元数据 修改作者、标题和其他属性。 查看元数据 查看 PDF 的隐藏属性。

    MusePDF 如何工作

    三步搞定，不用注册，不用安装。

    1. 选择工具

      打开对应的工具页 —— 合并、拆分、压缩、转换、签名、加密，另有 52 个。

    2. 拖入文件

      文件由浏览器在本地读取。本地模式下不上传，所以机密文件依然机密。

    3. 下载结果

      完成后的文件直接保存到你的设备。没有水印，没有注册墙，也不用排队。

    常见问题

    MusePDF 免费吗？

    这 60 个本地工具免费，不用注册、不加水印、没有每日次数限制。可选的云端功能会消耗服务器资源，因此按用量计费，部分会收费。

    我的文件会被上传吗？

    这 60 个本地工具不会上传 —— 它们在浏览器里运行，文件留在你的设备上。可选的云端功能（AI、超大文件）会为该步骤上传文件或它需要的文本。

    需要安装什么吗？

    不需要。MusePDF 在电脑、平板和手机的现代浏览器里都能用，加载后还可以离线工作。

    MusePDF 有多少个工具？

    MusePDF 有 60 个 PDF 工具，涵盖合并、拆分、转换、编辑、整理、优化和安全。

    使用云端功能时，我的文件会怎样？

    它只用于完成那一步的结果，而且云端步骤始终由你主动触发。
