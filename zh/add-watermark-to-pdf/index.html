对 PDF 的修改大多是临时起意：少了一个签名、要给同事标一处重点、合同上要加页码。添加水印 当场就能处理，不用装桌面软件、不用账号、不用订阅。批注结果会压平进页面里，收件人用什么阅读器打开，看到的都跟你一样。

不上传

文件在本地用 JavaScript 和 WebAssembly 读取 —— 这个工具不会把内容发送到服务器。

免注册

不用账号，不用邮箱，不用信用卡，也没有到期要记的试用期。

无水印

下载到的就是真正的文件 —— 干净、没有标记、可以直接打印。

添加水印常见问题

添加水印 之后我会得到什么？

你会得到带你文字或图片水印的 PDF。

要花钱吗？

不用花钱。完整功能免费用，不用注册、不留邮箱、不加不印水印，处理多少个文件也没有限制。

文件在哪里处理？

就在你自己的浏览器标签页里。不会上传到服务器，文件始终留在你的电脑上 —— 关掉标签页，数据也就没了。

手机上能用吗？能离线用吗？

可以。这个页面在电脑、平板和手机的现代浏览器里都能用，加载完之后断网也能继续用。

如何在不把文件上传到服务器的情况下完成PDF 水印？

添加水印 在你的浏览器里用 JavaScript 和 WebAssembly 读取文件，处理全部在你自己的设备上完成：不会上传到任何服务器，关掉标签页数据也就消失了。

PDF 水印免费吗？有没有次数或文件大小限制？

完全免费：不用注册、不留邮箱、没有水印，也没有每日次数上限。能处理多大的文件取决于你设备的内存，而不是某个上传配额。

PDF 水印的改动真的写进 PDF 了吗？

写进去了。用文字或图片给 PDF 加水印 —— 斜排、平铺或居中 —— 用来标记草稿和机密副本。保存后的文件在任何阅读器里看到的都是同一版内容。
